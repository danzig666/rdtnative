**Bring your own API key.** rdtnative comes without a Reddit API key: it only works with a
client ID you supply yourself.

### New

- **In-app updates:** rdtnative checks GitHub for a new version about once a day and offers to
  install it; Settings › Check for updates does it on demand. Installing goes through Homebrew
  Channel and closes the app.
- **Smooth pointer edge scrolling:** rest the Magic Remote pointer at the top or bottom edge and
  the feed, the comments or the subreddit list glide, faster nearer the edge (as in ytnative).
  It is off over videos and pictures.
- **Smoother look:** the selected post eases in, the two-pane preview fades between posts, messages
  fade in and out, and the video bar fades away.
- **RedGIFs and Streamable** posts play on the TV.
- **Pictures in comments:** images linked from Reddit or Imgur show under the comment.

### Fixed (Reddit changes since 2023)

- **"Load more replies" works again:** Reddit now blocks the old way to load them, so they come
  through focused comment pages instead.
- **Share links** (`reddit.com/r/…/s/…`) open the post they share; `reddit.com/media?url=…` links,
  posts on user profiles and `/gallery/…` links open correctly.
- **Galleries** no longer lose pictures Reddit marks as failed; deleted ones are skipped.
- **Videos** play the stream with sound (HLS) by default; Imgur, RedGIFs and Streamable play from
  their own host instead of Reddit's small preview.
- Imgur GIFs without an MP4, link previews of reddit.com posts, emoji flairs, NSFW results in search
  (your NSFW setting still applies), and short rate-limit pauses.

### Install

- **Homebrew Channel:** add the repository
  `https://github.com/danzig666/rdtnative/releases/latest/download/repo.json`.
- **By hand:** `ares-install --device <tv> io.github.danzig666.rdtnative_0.1.2_arm.ipk`.
