**Bring your own API key.** rdtnative comes without a Reddit API key: it only works with a
client ID you supply yourself. Signing in is explained in the
[README](https://github.com/danzig666/rdtnative#signing-in).

### Fixed

- **The app no longer closes right after it starts.** Some posts and comments (emphasis followed
  by a no-break space) made the text formatting crash, so the app closed as soon as one was on
  screen.
- **Galleries:** going to the next picture no longer flashes the first one before it.

### New

- **Recent subreddits** in the side menu: the subreddits you visited lately, with a way to clear
  the list.
- **Two panes:** the right pane now shows the whole thread under the post. Down goes through the
  comments, Right skips to the next thread and Left goes back to the list. A picture or video
  post still gets the whole pane.
- If the app ever runs into an error, its log now records where, to make it easier to fix.

### Install

- **Homebrew Channel:** add the repository
  `https://github.com/danzig666/rdtnative/releases/latest/download/repo.json`.
- **By hand:** `ares-install --device <tv> io.github.danzig666.rdtnative_0.2.3_arm.ipk`.
