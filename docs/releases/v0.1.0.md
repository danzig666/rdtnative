First release of rdtnative, a native Reddit client for LG webOS TVs, made for the Magic Remote.

**Bring your own API key.** rdtnative comes without a Reddit API key: it only works with a
client ID you supply yourself. Enter it in Settings › Reddit API with the remote, or scan the QR
code and paste it on your phone. There are ways to get a working API key; search Reddit for them.

### Install

- **Homebrew Channel:** Settings › Add repository:
  `https://github.com/danzig666/rdtnative/releases/latest/download/repo.json`, then install
  rdtnative from that repository. Updates show up there.
- **By hand:** download the `.ipk` below and install it with
  `ares-install --device <tv> io.github.danzig666.rdtnative_0.1.0_arm.ipk`.

### What it does

- Feeds: Home, Popular, All, subreddits, favourites, users, saved posts and search, with every sort
  and time range (remembered per subreddit) and endless paging.
- Six layouts: Two panes (a list with a live preview of the selected post and its top comments),
  Cards, List, Large, Compact and Dense.
- Posts: pictures, galleries, Reddit videos and GIFs (played by the TV), Imgur, YouTube (opens in
  ytnative or LG's YouTube app), links as QR codes, and Reddit formatting.
- Comments: threaded, collapsible, "load more" in place; Left/Right jump to the parent and the next
  thread.
- Signed in: vote, save, hide, join subreddits, reply and the inbox. Sign in with a QR code.
- Display: text size 70-175 % (separately for post and comment text), five fonts, five themes
  including OLED black, eight accent colours.
- Content: NSFW and spoilers blurred, hidden or shown; read posts dimmed or hidden; hidden
  subreddits and words.
- Remote: pointer and pointer edge scrolling, hold OK for menus, colour buttons (vote, save,
  comments), USB keyboard.

### Known limits

- Tested on the desktop simulator; the TV video player and sign-in still need wider testing.
- Videos need webOS 5 or newer (webOS 4 TVs show their QR code).
- Animated GIF and WebP pictures show as still pictures; GIF posts play as video.

`rdtnative-0.1.0.debug` holds the symbols for `cargo xtask crash`.
