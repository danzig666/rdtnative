**Bring your own API key.** rdtnative comes without a Reddit API key: it only works with a
client ID you supply yourself. Signing in is explained in the
[README](https://github.com/danzig666/rdtnative#signing-in).

### Fixed

- **The app speaks your language.** Its translations were never switched on, so it showed
  English on every TV. It now follows the TV's language (Hungarian, German, Spanish, French or
  Russian), including the sign-in screen announced in 0.2.1. Some labels are still in English.

### New

- **Settings › Display › Language:** use the TV's language or pick one.

### Install

- **Homebrew Channel:** add the repository
  `https://github.com/danzig666/rdtnative/releases/latest/download/repo.json`.
- **By hand:** `ares-install --device <tv> io.github.danzig666.rdtnative_0.2.2_arm.ipk`.
