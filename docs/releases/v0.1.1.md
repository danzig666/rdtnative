**Bring your own API key.** rdtnative comes without a Reddit API key: it only works with a
client ID you supply yourself. Enter it in Settings › Reddit API with the remote, or scan the QR
code and paste it on your phone. There are ways to get a working API key; search Reddit for them.

### Changes

- Settings › Reddit API and the phone setup page now just say to bring your own API key, without
  instructions for where to get one.
- Clearer help on the client ID and redirect URI fields, and a simpler message when Reddit rejects
  the client ID.

### Install

- **Homebrew Channel:** Settings › Add repository:
  `https://github.com/danzig666/rdtnative/releases/latest/download/repo.json`, then install or
  update rdtnative from that repository.
- **By hand:** download the `.ipk` below and install it with
  `ares-install --device <tv> io.github.danzig666.rdtnative_0.1.1_arm.ipk`.

See the [v0.1.0 notes](https://github.com/danzig666/rdtnative/releases/tag/v0.1.0) for the full
feature list. `rdtnative-0.1.1.debug` holds the symbols for `cargo xtask crash`.
